# 🚀 Rentify Deployment Guide

This guide describes how to deploy the Rentify application. You have two main options:

1. **Separate Deployments (Recommended)**: Deploy the React frontend to Vercel (as a fast static CDN) and the Express backend to a persistent host like **Render**, **Railway**, or **Fly.io**.
2. **Single Monorepo Deployment**: Deploy both frontend and backend together on **Vercel** using Vercel Serverless Functions.

---

## 🔑 Prerequisites

Before deploying, ensure you have:
1. A **MongoDB Atlas** account and database connection string (`MONGO_URI`).
2. A **Cloudinary** account to host uploaded property images (`CLOUD_NAME`, `CLOUD_API_KEY`, `CLOUD_API_SECRET`).
3. A **JWT Secret Key** (a long random string) to sign login tokens (`JWT_SECRET`).

---

## 🛠️ Option 1: Separate Deployments (Recommended)

This is the standard MERN-stack architecture. It avoids serverless limitations (like 10-60s timeout limits, cold starts, and database connection limits).

### 1. Deploy the Backend (Server)

You can deploy the backend to [Render](https://render.com/), [Railway](https://railway.app/), or [Fly.io](https://fly.io/).

**Steps (example using Render Web Services):**
1. Sign in to Render and click **New > Web Service**.
2. Connect your Rentify Git repository.
3. Configure the following service settings:
   - **Root Directory**: `server`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
4. In the **Environment** tab, add your environment variables:
   - `MONGO_URI` (your MongoDB Atlas connection string)
   - `JWT_SECRET` (your jwt secret key)
   - `CLOUD_NAME` (Cloudinary cloud name)
   - `CLOUD_API_KEY` (Cloudinary API key)
   - `CLOUD_API_SECRET` (Cloudinary API secret)
   - `PORT` (usually set automatically by the platform, or defaults to 5000)
5. Deploy the web service. Note the backend URL generated by Render (e.g., `https://rentify-backend.onrender.com`).

### 2. Deploy the Frontend (Vercel)

1. Go to the [Vercel Dashboard](https://vercel.com/dashboard) and click **Add New > Project**.
2. Import your Rentify Git repository.
3. Configure the project settings:
   - **Project Name**: `rentify-client`
   - **Framework Preset**: `Vite`
   - **Root Directory**: `client`
4. Under **Environment Variables**, add:
   - `VITE_API_URL` = `https://rentify-backend.onrender.com/api` (replace with your actual backend URL + `/api`)
5. Click **Deploy**. Vercel will build the frontend and serve it.

---

## 📦 Option 2: Single Monorepo Deployment (Vercel Only)

We have configured `vercel.json` at the root of the project to allow both frontend and backend to run in a single Vercel project using serverless functions.

### Steps to Deploy:
1. Go to the [Vercel Dashboard](https://vercel.com/dashboard) and click **Add New > Project**.
2. Import your Rentify Git repository.
3. Configure the project settings:
   - **Root Directory**: Leave it blank (the root `/` of your repository, where `vercel.json` is located).
   - **Framework Preset**: **Other** (since `vercel.json` overrides and builds the Vite client and Express backend).
4. Under **Environment Variables**, add the environment variables for **both** frontend and backend:
   - `MONGO_URI`
   - `JWT_SECRET`
   - `CLOUD_NAME`
   - `CLOUD_API_KEY`
   - `CLOUD_API_SECRET`
   - `VITE_API_URL` = `/api` (this routes API calls locally on the same domain, e.g. `/api/auth/login`)
5. Click **Deploy**. Vercel will install dependencies, build the client static site, and deploy the server routes.
